# Embedded PDF fonts

Noto Sans Regular/Bold provide Latin and Cyrillic glyphs without depending on fonts
installed on the host. The static TrueType files come from the official Noto repository:

- https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans
- https://github.com/notofonts/noto-fonts/blob/main/LICENSE

Redistributed under the SIL Open Font License 1.1; see `FONT-LICENSE.txt`.
The fonts are embedded only by the mock PDF renderer.
